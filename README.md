# BunBetsu

Intelligent Waste Managment Platform for College Events

---

## Main Components:

### 1. Waste Prediction Model

- evidence-backed mathematical model that predicts total waste generated in the event based on the user input and collected evidences
- gives very rich information about the composition of waste and what amount of it can be recycled.
- also prepares data for rich visualization of the waste-prone areas
- uses XAI to disclose the relevant evidence used for prediction and calculation
- one of the data inputs for the Bin Distribution Model.
